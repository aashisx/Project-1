# Vehicle Rental Front End

A simple vehicle-rental front-end project built with HTML, CSS, and JavaScript.

## Structure

- `index.html`, `about.html`, `booking.html`, `login.html`, `shop.html` — site pages
- `assets/css/` — page stylesheets
- `assets/js/` — page scripts
- `assets/images/` and `assets/media/` — project images and video
- `assets/vendor/` — third-party browser libraries (jQuery and Tabx)

Open `index.html` in a browser to run the site.
